## [0.1.0] - 2026-08-17

### Added

- Native OBS Tools menu integration and a separate teleprompter window.
- Markdown script folders, sorting, editing, saving, and formatted fullscreen rendering.
- Fullscreen scrolling with pause/resume, speed, margin, and font-size controls.
- Keyboard controls and persistent settings.
- Centered fullscreen lead-in and ending space with non-shifting control overlays.
